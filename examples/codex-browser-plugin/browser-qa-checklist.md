# Browser QA Checklist

使用 Codex Browser 插件验收前端页面时，可以按这份清单执行。

## 基础渲染

- [ ] 页面是否成功打开
- [ ] 是否出现空白屏
- [ ] 是否有控制台错误
- [ ] 主要内容是否在首屏可见
- [ ] 字体和颜色是否符合预期

## 响应式布局

- [ ] 桌面端布局正常
- [ ] 移动端 390px 宽度正常
- [ ] 标题是否溢出
- [ ] 按钮文字是否换行或被截断
- [ ] 卡片/表格是否超出屏幕
- [ ] 弹窗是否在小屏幕被遮挡

## 交互

- [ ] 主要按钮可点击
- [ ] 表单输入正常
- [ ] 表单提交有反馈
- [ ] loading 状态可见
- [ ] 错误状态可见
- [ ] 成功状态可见

## 可用性

- [ ] 关键操作路径少于 3 步
- [ ] 页面上没有误导性按钮
- [ ] 空状态有明确提示
- [ ] 错误信息能指导用户下一步

## 回归确认

- [ ] 修复后重新打开页面
- [ ] 修复后重新截图
- [ ] 修复没有引入新的布局问题
- [ ] 最终结果可以描述清楚
