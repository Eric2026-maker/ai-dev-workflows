# AI Test Generation Example

这个案例演示一个更实用的 AI 编程工作流：

> 不要直接让 AI 写测试。先让 AI 分析风险路径，列出测试用例，再生成测试骨架。

## 场景

假设项目里有一个订单金额计算函数：

- 支持商品小计
- 支持优惠券
- 支持会员折扣
- 支持运费
- 最终金额不能为负

这种函数很容易遗漏组合条件，比如：

- 优惠券金额大于商品金额
- 会员折扣和优惠券同时存在
- 运费为 0
- 输入为空或非法
- 浮点金额精度

## 工作流

1. 把函数代码交给 AI。
2. 要求 AI 先输出测试策略。
3. 要求 AI 列测试用例表。
4. 人确认测试点。
5. 再让 AI 生成测试骨架。

## 文件

- `price-calculator.js`：示例业务函数
- `test-cases.md`：AI 应该先产出的测试用例表

## 推荐 Prompt

使用：

```text
templates/test-generation-prompt.md
```

核心原则：

- 先测什么，再写代码。
- 不确定测试框架时先给伪代码。
- 优先覆盖高风险路径。
- 不让 AI 编造业务规则。
